# HGAP website rebuild: wireframes

Clickable wireframes and guides for the Hitachi Global Air Power website rebuild. Plain HTML: every page is self-contained (no extra files to upload).

**Start here: `dashboard.html`**

| File | What it is |
|---|---|
| `dashboard.html` | Hub: previews of every page, homepage section list, template status, decisions, assets, links |
| `index.html` | Homepage V2 (approved). Resize the window to see mobile |
| `mobile-preview.html` | Homepage in a 390px phone frame |
| `sitemap.html` | Navigation, footer and policy pages |
| `menus.html` | Every desktop and mobile menu state, with spec and content |
| `brand.html` | Brand guidelines with brand-in-action examples |
| `clickup-brief.md` | Design brief, ready to paste into ClickUp |
| `design-spec.md` | Brand tokens, components and interactions |

## Notes

- Every page is set to `noindex`, so search engines won't list it. Anyone with the link can still view it.
- Fonts load from Google Fonts (Figtree stands in for the Hitachi typeface).
- Bracketed text, like `[PHOTO: ...]`, marks content still needed from the client.
